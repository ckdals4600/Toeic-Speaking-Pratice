# 토스 스피킹 카드

토익스피킹 문장을 **한글 뜻만 보고 영어로 말해본 뒤** 정답을 확인하는 스피킹 암기 카드입니다.
휴대폰 브라우저에서 바로 쓰도록 만들었습니다.

## 쓰는 법

1. 카드에 한글 뜻이 나옵니다. **소리 내어 영어로 말해봅니다.**
2. 카드를 탭하면 영어 정답이 나옵니다.
3. `발음 듣기`로 원어민 발음을 확인합니다. 속도는 0.7x / 0.85x / 1.0x.
4. 아래 `다시` 또는 `알았어`를 눌러 채점합니다.

## 출제 방식

틀린 문장이 더 자주 나오되 한쪽으로 치우치지 않게 맞췄습니다.
카드마다 숙련도가 0~5단계로 오르내리고, 단계가 낮을수록 자주 뽑힙니다.
실제 측정치는 **가장 안 외워진 카드가 가장 잘 외워진 카드보다 약 2.4배 자주** 등장하며,
모든 카드가 빠짐없이 계속 나옵니다. 직전에 본 카드는 잠시 제외됩니다.

설정에서 가중치를 끄면 완전 무작위가 됩니다.

## 기타

- 학습 기록은 브라우저 localStorage에 저장됩니다. 기기를 바꾸면 이어지지 않습니다.
- 발음은 브라우저 내장 음성합성(Web Speech API)을 씁니다. 크롬 사용을 권장합니다.
- 설정에서 `한글 뜻 먼저 보기`를 끄면 영어를 보고 한글을 맞추는 역방향 모드가 됩니다.
- 데스크톱 단축키: `스페이스` 확인/정답, `1` 다시, `2` 알았어, `P` 발음.

빌드 과정 없는 단일 `index.html`입니다. 파일을 열기만 해도 동작합니다.
